# High Throughput Producer

This is just a simple Go service that producers a high volume of events to a Kafka topic.
It is intended to demonstrate the ability of the system to handle high throughput. 

## Features
- Written in Go
- Produces a high volume of events to Kafka
- Demonstrates multi-language consumer setup

## Running the High Throughput Producer Service

This service is intended to be run as part of a Docker Compose setup.
Please refer to the main project README for instructions on setting up and running the entire system.
